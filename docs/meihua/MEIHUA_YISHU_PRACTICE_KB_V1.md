## 一、结论与使用边界

梅花易数的核心不是“看到某个卦名就套一句话”，而是：先确认起卦合法且问题单一，再依次判断体用、五行生克、旺衰、主互变过程、卦象与爻辞，最后结合外应和现实背景收窄结论。

本知识库当前完成了基础规则、感情专项流程、应期边界和一个实战案例。它能够支持规范的人工解卦，但还不能证明预测准确率，也没有正式写入 MingLi Runtime。后续必须通过盲测案例持续校正。

术数定位：传统文化研究与决策反思工具，不把卦象当作可证实事实，不替代医疗、法律、投资及重大关系决策。

## 四、起卦规则

### 1. 时间起卦

原典常用农历数与地支数：

- 上卦数 = 年支数 + 农历月数 + 农历日数；除以 8 取余。
- 下卦数 = 年支数 + 月数 + 日数 + 时支数；除以 8 取余。
- 动爻数 = 年支数 + 月数 + 日数 + 时支数；除以 6 取余。
- 除 8 余 0 按 8，即坤；除 6 余 0 按第六爻。
- 地支数：子 1、丑 2，顺排至亥 12。

必须保存：公历时刻、时区、地点、对应农历年月日、时支、采用的换日规则。若排盘应用只给出结果而不给公式，能够解卦，但不能验证起卦是否正确。

### 2. 数字起卦

常用两组数分别取上、下卦，两数之和取动爻；均按“卦除八、爻除六”。数字必须在提问当下自然获得，不能为了得到想要的卦反复挑数。

### 3. 物象、声音、文字起卦

原典允许以可数之物、声音次数、字数笔画、人物、方位及异常外物起卦。关键限制是“有触发才占”：同一件事不要在短时间内反复起卦，否则得到的更可能是情绪噪音而不是新信息。

### 4. 起卦有效性门槛

以下任一缺失，结论降级：

- 问题不单一，如同时问复合、结婚、出轨与时间；
- 起卦方式未知；
- 起卦时间或时区不明；
- 同题短期重复起卦，却未说明第一次卦；
- 事后挑选“最像”的一个卦；
- 缺少现实背景，导致同一卦象可映射成多个互斥故事。

## 五、成卦后的结构

### 1. 本卦、互卦、变卦

- 本卦：事情起点和当前结构。
- 互卦：由二三四爻为下互、三四五爻为上互，观察中间过程、内因或隐藏环节。
- 变卦：唯一动爻阴阳翻转后形成，观察后续落点。

“本卦是现在、互卦是中间、变卦是结果”是实战的主时间轴，但不是机械的三段剧情。卦象必须服从所问主题与现实条件。

### 2. 体卦与用卦

- 动爻所在的三爻卦为用卦；另一卦为体卦。
- 体：求测者、主体、承受方。
- 用：所问的人、事、关系或外部作用。

基础关系：

| 关系 | 基础含义 | 感情中的常用解释 |
|---|---|---|
| 用生体 | 外部助体 | 对方主动、关系对求测者有益、较易推进 |
| 体用比和 | 同类相应 | 双方较合拍，推进阻力小 |
| 体克用 | 体能制用 | 可推进但常较慢，求测者更掌控 |
| 体生用 | 体泄于用 | 求测者投入较多，关系较费力 |
| 用克体 | 外部伤体 | 对方或关系给求测者压力，成则亦有代价 |

这张表只定“关系动力与吉凶倾向”，不直接回答对象姓名、是否旧人、是否已婚等事实问题。

### 3. 综卦、错卦

综卦可作换位视角，错卦可作反面结构；二者只用于补充，不得压过本卦、体用、互卦、变卦和动爻。很多现代排盘会自动展示，但原典主判链并不要求每次都用。

## 六、统一断卦顺序

1. 固定问题：谁问、问谁、问什么结果、时间范围多长。
2. 校验起卦：方式、时间、时区、数字或外应来源。
3. 排结构：本卦、互卦、变卦、动爻、体卦、用卦。
4. 定基础动力：体用生克与比和。
5. 看体势：季节旺衰、体党与用党，作为强弱修正。
6. 看过程：本卦起点、互卦中段、变卦落点。
7. 取象落题：只选与问题直接有关的象，不罗列万物类象。
8. 参卦辞爻辞：先天数起卦以卦理为主；后天物象起卦更重卦爻辞。现代应用若未说明类型，两者都看，但须说明不确定性。
9. 看外应：只记录起卦当时自然出现的声音、人物、方向、颜色与动作；不得事后拼凑。
10. 定应期：先判断事件尺度，再用生体/克体之卦、卦数、方位时序及求测者动静收窄；不可只凭一个数字断某日。
11. 现实反证：若现实已有明确新人、长期断联、异地、婚姻状态等，优先纳入。
12. 输出一条主断、两三条依据、一条条件，不堆满所有象意。

## 七、感情专项

### 1. 基本映射

- 体卦：求测者。
- 用卦：所问对象或下一段关系。
- 用生体：对方较主动、容易靠近；体生用：求测者付出较多；用克体：关系压力较大；比和：相处较自然。
- 咸可提示感应与吸引，姤可提示相遇或突发接触，复可提示回头、再现、恢复，也可能只是重启感情状态；中孚可提示信任、真诚与确认。任何一个卦名都不是“新人/旧人”的固定标签。

### 2. 新人还是旧人的判定门

不能只因互卦出现“复”就断旧人。至少检查三条证据链：

1. 时间链：本、互、变是否呈现“旧事中途重现，并走向实际关系”。
2. 体用链：用是否生合体，旧人的回头是否对主体形成有效推进，而非只出现消息或情绪。
3. 现实链：当前是否存在明确旧人、是否仍有联系方式、是否有过复联迹象；若现实完全没有旧人条件，“复”可解释为恢复恋爱状态或重复旧模式。

判定等级：

- 高：三条链一致，并有现实反馈。
- 中：卦中两条链一致，现实条件未知。
- 低：仅凭单一卦名、错综卦或网络口诀。

### 3. 复合类四层

感情复合不得只说“有缘”：

1. 缘分牵引：是否仍有关注、情绪或未了结事项。
2. 复联可能：是否会重新联系。
3. 复合可能：联系能否转成关系。
4. 稳定可能：旧矛盾是否被处理，关系能否持续。

互卦出现“复”最多先支持前两层；要断第三、第四层，必须看体用、变卦与现实阻碍。

## 八、应期规则与风险

原典提供卦数、卦气、干支方位及行卧坐立迟速等多种应期法。它们可能给出不同答案，因此应采用“事件尺度优先”的收敛规则：

- 即时消息、见面：日或时。
- 暧昧与确认关系：周或月。
- 婚姻、迁移、长期事业：月或年。

生体之应通常较快，互卦之应在中段，变卦之应较后。若没有明确时间范围、起卦方法和外应，不给精确日期，只给宽窗口。应期是当前最需要案例校准的部分，不得包装成确定日期。

## 九、结构校验例：山泽损之风泽中孚

### 1. 卦象资料

- 本卦：山泽损。
- 互卦：地雷复。
- 五爻动，变卦：风泽中孚。
- 综卦：风雷益；错卦：泽山咸。
- 体卦：兑金；用卦：艮土。

### 2. 结构校验

五爻在上卦艮，故上卦为用；下卦兑不动，为体。艮土生兑金，属于用生体。五爻变后，上艮变巽，下兑不变，得到风泽中孚。互卦地雷复亦与图中一致。

这组“损五爻变中孚、互见坤震”的结构，恰好出现在《梅花易数》卷一“西林寺牌额占”的改字后例中。原典将其判为用与互有生体之助、总体为吉。该原例只能证明结构算法和吉凶逻辑相符，不能把寺院案例的具体事件套到感情上。

### 3. 可验证结论

- 五爻在上卦，所以上艮为用、下兑为体。
- 艮土生兑金，为用生体。
- 二三四爻组成下互震，三四五爻组成上互坤，互卦为地雷复。
- 第五爻阴变阳，上艮变巽，下兑不变，变卦为风泽中孚。
- 这个结构可支持“用生体、总体有助”的基础判断；不能脱离具体问题、起卦方式、时令和现实背景，直接推断某个个人事件。

本节只记录公开经典同构卦例和确定性结构计算，不包含用户资料、真实案例结果或产品准确率声明。

## 十一、进入系统前的验证门

当前状态：`manual_assist=true`，`runtime_enabled=false`。

进入命理师 V2.0 自动运行前，至少完成：

1. 20 个已知结果案例回测，只用于发现规则歧义，不计准确率。
2. 30 个前瞻盲测案例，预测先封存，之后回收事实。
3. 新人/旧人、复联/复合/稳定、事业成败、失物、短期应期分别统计，不能混成一个“总命中率”。
4. 记录基准率；例如多数人的下一段关系本来就可能是新人，不能把基准率当术数能力。
5. 禁止模糊命中：新人和旧人两边都说、无限延长时间窗、事后换象，都计为失败或不可判定。
6. 只有规则可重复、输入可审计、盲测优于基准，才考虑写入代码和 Runtime。
