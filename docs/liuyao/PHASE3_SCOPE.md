1. 高级结构事实：伏神/飞神候选、十二长生、进退神、逐支反吟伏吟、多动爻关系图。

3. 事件合同驱动的自动取用与专项主题包。
4. 条件化应期候选；不直接生成确定日期或未经校准的成功概率。
