# 六爻高级结构层 v1

## 目标

本层补齐可以确定性计算、或可以在明确条件下登记为结构证据的六爻能力。它位于：

```text
确定性排盘 → 基础结构解释 → 高级结构计算 → 人工复核 → 预测版本登记
```

版本边界固定为：

```text
method_id=liuyao-advanced-structure@0.2.0
interpretation_status=review_only
production_allowed=false
prediction_validity=not_evaluated
```

该边界表示这些结构可用于排盘复核和形成候选证据，不表示已经证明现实预测有效，也不允许把结构分数直接改写成成败概率。

## 已实现能力

### 自动月建、日辰与旬空

`calendar-context` 从案例冻结的 `completed_at` 读取当地日期、时间和固定 UTC 偏移，复用仓库已有的 `DeterministicBaziEngine`：

```text
bazi-deterministic-lichun-jie-noaa-v0.1
```

生成节气月建、日柱、日支、旬空、当前节气锚点及可复算哈希。若案例已经手工填写月建或日柱，手工值必须与重算结果一致；不一致返回 `CALENDAR_CONTEXT_CONFLICT`。

高级结构会先生成有效历法上下文，再用派生后的月建、日辰重新构建命盘并调用第二阶段解释层。输出同时保留原命盘、有效命盘、原请求和有效请求的 SHA-256，避免出现“高级层用了自动月日，基础层仍按缺省月日解释”的分层不一致。

当前只消费 `completed_at` 自带的固定 UTC 偏移，不从 `location` 文本猜经纬度或 IANA 时区，不做真太阳时修正。UTC 偏移必须精确到整分钟；超出共享历法引擎年份范围或处于其不确定节气边界时失败关闭。

### 伏神与飞神

本层读取本卦所属八宫的本宫纯卦，检查当前六爻是否缺少某一六亲。缺失六亲按本宫纯卦的同位爻登记为伏神，同位可见爻登记为飞神。结果包含：

- 伏神爻位、纳甲、地支、五行和六亲；
- 飞神六亲、地支和五行；
- 飞神对伏神、伏神对飞神的五行关系；
- 伏神在月、日的十二长生阶段。

这只是飞伏结构收据。飞生伏、飞克伏、伏生飞或伏克飞不会单独推出成败；伏神能否出伏仍需月日、空破和动变条件。

### 十二长生、墓与绝

口径固定为：

```text
liuyao-five-element-forward-growth-stage@1.0.0
```

按卦爻五行顺行计算：

```text
木从亥长生
火从寅长生
金从巳长生
水、土从申长生
```

依次排列长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。每个本爻按其五行计算月支和日支阶段，动爻同时计算变爻阶段。

“墓”“绝”只作为条件化结构，不是一票否决。它们与临月、月生、临日或日生并见时，冲突矩阵保留两类证据并返回 `GROWTH_STAGE_ENVIRONMENT_CONFLICT`。

### 月破、日冲、六合与六冲

高级关系图为月建、日辰与六爻登记：

- 同支；
- 六合；
- 六冲；
- 五行生、克、同类、泄耗和反制关系。

月建六冲标记月破。日冲、六合只登记事实；合起、合绊、冲起、冲散及合化仍不在本层自动裁决。合冲并见时返回 `COMBINE_CLASH_CONCURRENT`，不挑选对结论有利的一侧。

### 进神与退神

动爻与变爻按固定地支对识别：

```text
进：亥→子、寅→卯、巳→午、申→酉、丑→辰、辰→未、未→戌、戌→丑
退：以上各对反向
```

输出只写 `advance`、`retreat` 或 `none`。原爻同时旬空或月破时返回 `ADVANCE_RETREAT_VALIDITY_CONDITIONAL`，不会直接把化进写成增强，或把化退写成减弱。

### 反吟与伏吟

本层比较本卦与变卦同位纳支：

- 同支登记 `fuyin`；
- 六冲登记 `fanyin`；
- 按单爻、内卦、外卦和全卦范围汇总。

只有存在动爻时才登记反伏吟结构。该 profile 只表达同位纳支重复或相冲，不自动等同于失败、灾祸或反复发生。

### 多动爻关系图

关系图包含：

- 月建、日辰到六个本爻；
- 每个动爻到其他本爻；
- 每个变爻到六个本爻；
- 飞神与伏神的双向关系。

每条边保存地支关系、五行关系、作用状态和限制。动爻或变爻逢空、月破时，边标为条件性，不进入终局传递裁决。

### 原神、忌神、仇神条件化标记

相对所选用神五行，每个可见爻和伏神可标记为：

- 用神候选；
- 原神候选：生用神；
- 忌神候选：克用神；
- 仇神候选：受用神所制、同时在五行链上克原神并生忌神；
- 同类候选；
- 泄神候选。

角色名称只说明五行相对关系。是否有力仍由动静、月日、旬空、月破、墓绝、飞伏和动变共同约束。

### 用神候选自动排序

排序只解决“多候选时先复核哪一爻”。因素全部随结果输出，包括可见或伏藏、月日关系、空破、动静、十二长生、回头生克、进退及飞伏关系。

可能状态：

```text
ranked_leader
provisional_leader
narrow_margin
tie
hidden_leader_requires_confirmation
explicit_primary
no_candidate
reality_blocked
```

`score` 是固定、透明的复核排序工具，语义明确为：

```text
heuristic_review_score_not_probability
```

只要领先候选依赖条件化因素，整体状态为 `needs_confirmation`；调用方明确指定的主爻不会被排序静默替换。

### 规则冲突矩阵

当前矩阵处理：

- 现实阻断覆盖盘面支持；
- 用神排序并列或分差不足；
- 显式主爻与排序领先项不同；
- 旬空与日冲并见；
- 月破与发动并见；
- 进退神与原爻空破并见；
- 回头生克与变爻空破并见；
- 墓绝与月日直接生扶并见；
- 六合与六冲同时作用；
- 飞神克伏神；
- 伏神存在但出伏条件未闭合；
- 同一候选同时存在支持与约束因素。

冲突不会被删除。输出按优先级保留现实覆盖、人工确认、保留正反、延迟定向或 unresolved 等处理结果。

## CLI

```bash
mingli-liuyao calendar-context --record case.json

mingli-liuyao advanced-interpret \
  --record case.json \
  --request interpretation-request.json

mingli-liuyao advanced-benchmark
```

考编、感情、求孕等主题边界继续由第二阶段负责；高级层不能绕过“体制适配度不能由单次六爻单独推出”“医学确认必须由检查完成”等限制。

## 来源与证据边界

传统计算口径取自用户提供资料：

- 《周易预测宝典》第 75 个物理页明确列出木亥、火寅、金巳、水土申的五行长生起点；
- 同书第 164 页给出原神、忌神、仇神的相对五行定义；
- 第 168–169 页列出进神、退神地支对，以及飞神、伏神的基本定位；
- 第 204 页和第 207 页分别说明反吟与伏吟的同位纳支关系；
- 《周易与预测学》的目录把纳甲、六亲、六神、动变、四时旺衰、反伏吟和应期分为不同层次，本实现据此保持结构计算与应期/吉凶分层。

资料用于冻结传统术语和算法口径，不构成现实预测有效性的科学证明。所有输出继续以现实证据和专业意见为上位约束。
