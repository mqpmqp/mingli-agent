## 证据分级

来源条目必须保留下列层级，禁止把它们扁平化为同等权重：

```text
author_rule            作者直接陈述的规则或方法边界
attributed_quote       作者明确引述野鹤、《黄金策》等前人文字
author_case            作者提供并自行解释、反馈的案例
classic_reinterpretation 古例由作者重新纳甲或解释
mixed_method_case      八字、体用、六爻等混合使用的案例
source_text_anomaly    原页存在疑似错字、漏字或语法歧义
not_found              在本次三本资料中未找到可支持的通则
```

其中 `author_case`、`classic_reinterpretation` 和 `mixed_method_case` 只能支持候选规则或反例边界，不能单独升级为普遍规则。

## 一、旬空、出空、填实与冲空

### 1. 旬空不是永久删除

`S11` 第 94–95 页直接解释：“空者，主时间不到，时间到了就不为空”，并以财爻出空后得财说明“出空不空”。这支持把旬空建模为当前时效条件，而不是永久删除节点。

`S15` 印刷第 237 页 / PDF 第 252 页、`S11` 第 220 页进一步区分：

- 世爻、用神旬空，吉凶可在出空或填实之时发生；
- 用神旬空发动，仍以出旬、值日作为成事条件；
- 空而逢合，待冲开；
- 空而逢克，待出空或制杀；
- 空而入库，待冲库。

因此“动不为空”最多表示动爻没有被永久取消，不能解释为动爻在旬内已经完全具备当前力量或立即兑现。

### 2. 当前力量与结构资格必须分开

`S15` 印刷第 181 页 / PDF 第 196 页、`S11` 第 165 页把“原神旺动而临空化空”列为原神生用条件，并说临空化空“并非无用”。但紧接着的案例又说静态亥水旬空“不受其生”，须待巳日冲起后病愈（`S15` 印刷第 182 页 / PDF 第 197 页；`S11` 第 166 页）。

这不是可由单一布尔值覆盖的关系。至少应拆为：

```text
structural_eligibility  是否仍是可参与的候选节点
current_force           当前是否能够实施或承受生克
manifestation_state     是否仍待出空、填实、冲空等条件
```

### 3. 冲空

`S15` 印刷第 217 页 / PDF 第 232 页、`S11` 第 200 页原文为：“爻遇旬空，日建冲之而为用，谓之冲空则实。”这可支持一个精确的 `CLASH_VOID` 候选规则，但只能关闭空这一项义务，不能顺手关闭同一节点上的月破、墓、绝、合绊或其他条件。

`S10` PDF 第 256 页 / 印刷第 239 页也写有“日建冲者不为空”，但该段明确处于终身预测并以世爻为主语。它只能支持 `topic=lifelong`、`node_role=self_line` 的限定口径，不能扩展成所有爻、所有问事的全局规则。

### 4. 旺动不空的作用域冲突

`S15` 印刷第 219 页 / PDF 第 234 页、`S11` 第 202 页引述野鹤：“旺不为空，动不为空，有日建动爻生扶者不空……”这是 `attributed_quote`，不是作者自行建立的无条件优先级。

`S10` PDF 第 227 页 / 印刷第 210 页则有应爻卯木临月建但仍因旬空、世爻克应而断事不成的复合案例。该例不能证明“临旺仍必为空”，但足以否定将“旺不为空”实现为无条件、全主题的硬覆盖。

保守实现应在规则未限定题型、爻位和角色时保留概念上的 `RULE_PROFILE_CONFLICT`；本批运行时统一落为节点义务 `RULE_EFFECT_CONFLICT`，并另输出 `AUTHOR_INTERNAL_CONFLICT` 收据。不得用加载顺序决定胜负。

### 5. `SOURCE_TEXT_ANOMALY`：旬空/冲空疑似错字

`S15` 印刷第 219 页 / PDF 第 234 页和 `S11` 第 202 页原页均写作：

> 旬空、填空之日不为空，出旬之时不为空。

同段上文列举的是“冲空、填空”，且 `S15` 印刷第 217 页 / PDF 第 232 页、`S11` 第 200 页另有明确的“冲空则实”。因此这里可能是“冲空”误印为“旬空”，但审计层不得静默改字。

应记录：

```text
reason_code=SOURCE_TEXT_ANOMALY
anomaly_id=VOID_FILL_WORDING_219_202
source_text=旬空、填空之日不为空
candidate_reading=冲空、填空之日不为空
resolution=unresolved_editorial_text
```

语义实现若需要 `CLASH_VOID`，应引用前述无歧义的“冲空则实”，不能用候选改字冒充原文。

## 二、月破、日破与真破

### 1. 月破是当前约束，不是永久删除

`S15` 印刷第 215 页 / PDF 第 230 页、`S11` 第 198 页定义“月建冲爻为月破”，并写明：

- 目下虽破，出月不破；
- 填实之日不为破；
- 逢合之日不为破。

同页又说普通“日辰生之”仍不能生起月破之爻。因此必须区分：

```text
DAY_GENERATION       普通日辰生扶，不能自动关闭月破
FILL_MONTH_BREAK     值破支之日的填实候选
COMBINE_MONTH_BREAK  逢合候选
EXIT_BROKEN_MONTH    出月候选
```

解除“破”也不等于自动旺相。`S11` 第 280 页另有“虽逢月破，但日辰合之，乃休囚待时而用”，说明解除或缓解月破后仍要重新评估休囚、旺衰和生克。

### 2. 真破是多条件合取

`S15` 印刷第 216 页 / PDF 第 231 页、`S11` 第 199 页把下列条件合并后称为“真破”：

- 爻静而不动；
- 无日辰、动爻生助；
- 又值旬空；
- 休囚无气；
- 再受月建、日辰或动爻克害。

因此不能由单一 `MONTH_BREAK` 直接生成不可逆的 `invalid`。即使实现兼容原因码 `TRUE_BREAK_CANDIDATE`，也必须保留其成员条件和来源轨迹。

### 3. 日冲先分暗动与日破

`S15` 印刷第 217 页 / PDF 第 232 页、`S11` 第 200 页明确区分：

- 日辰冲旺相静爻，为暗动；
- 日辰冲休囚衰弱静爻，为日破、爻破而无用。

所以日冲不能一律激活动爻路径，也不能一律裁掉路径。在旺衰、月日和来源未闭合前，应保留 `STATIC_DAY_CLASH_MOTION_UNRESOLVED`。

### 4. 月日强节点保护

同页还写：

- 爻逢月建，日冲而不散；
- 爻逢日建，月冲而不破。

这只能关闭对应的冲散或月破义务，不能把节点上的其他开放义务一并清空。

### 5. 不存在可核验的月破/日破总优先级

`S10` PDF 第 172 页 / 印刷第 155 页和 PDF 第 243–244 页 / 印刷第 226–227 页均在多个条件并存时使用日破或月破：六冲、多动、回头克、化鬼、官鬼旺等同时存在。`S10` 没有给出月破与日破冲突时谁先谁后的统一规则。

因此不得补造：

```text
MONTH_BREAK_ALWAYS_OVERRIDES_DAY_CLASH
DAY_BREAK_ALWAYS_OVERRIDES_MONTH_SUPPORT
```

同优先级来源相反或作用域不清时，应保持 `RULE_EFFECT_CONFLICT` 或 `unresolved`。

## 三、墓、库、入墓与冲库

### 1. 来源原词

`S15` 印刷第 94 页 / PDF 第 109 页在十干章节写“墓即库，即为入库”。六爻正文更常使用：

```text
入库
化库
冲库
冲开库
库之破
```

三本资料没有检出可核验的普遍规则原词“冲墓”。`S11` 仅有孤立案例语句“戌墓动开”，不能据此伪造“凡墓逢冲必开”的通则。

规范层若需要统一概念，可使用：

```text
normalized_relation=storage_release_by_clash
source_term=冲库 | 冲开库 | 库之破 | 戌墓动开
```

不得把规范名反写成不存在的来源引文。

### 2. 一般应期口径

`S15` 印刷第 236 页 / PDF 第 251 页、`S11` 第 219 页说原神入库、化库，待冲库之时为应期；`S15` 印刷第 238 页 / PDF 第 253 页、`S11` 第 221 页又说合局中入库、化库，待冲库之期。

“冲开库”另有精确命中：`S11` 第 296 页写“待冲开库之时”，其平行段落见 `S15` 印刷第 358 页 / PDF 第 373 页“冲开库之日安”。因此实现可保留该来源术语，但必须把这两处页码逐条绑定，不能只引用冲库案例代替。

这支持“冲库是解除候选”，不支持“冲库后必然吉”。冲开后仍须计算：

- 被冲开的节点角色；
- 节点自身旺衰；
- 原神、忌神和用神的生克；
- 同时存在的空、破、绝、合绊等义务。

### 3. 角色极性

`S10` 提供了方向相反的案例：

- PDF 第 228 页 / 印刷第 211 页：所求子孙用神入墓、化绝并受克，作为不利条件；
- PDF 第 230 页 / 印刷第 213 页：代表疾病的官鬼忌神入墓则“不能为害”，临绝则被控制。

`S15` 印刷第 237 页 / PDF 第 252 页、`S11` 第 220 页也明确说，测凶危之事时，忌神入库、化库、化绝、化死等反而为好。

因此 `TOMB_EFFECT_OPEN` 和 `ABSOLUTE_EFFECT_OPEN` 本身没有固定吉凶，必须在 `role_polarity` 确认后再解释。

### 4. 冲库个案的主题限制

`S10` PDF 第 245 页 / 印刷第 228 页以“亥水动化辰官库”断被捕入狱，又以丑冲未库断出狱。该例支持牢狱、封闭、受困类主题中的：

```text
enter_storage -> constrained
clash_storage -> release_candidate
```

它是 `author_case`，不能单独扩展为所有题型的无条件规则。一般化的“待冲库”应引用邵书的应期章节，而不是只依赖该牢狱案例。

### 5. 墓绝可被救应

`S15` 印刷第 359 页 / PDF 第 374 页、`S11` 第 338 页写：“用神遇库绝之地，及动而化墓、化绝，须看衰旺，用神旺者，无虑。”紧接着印刷第 360 页 / PDF 第 375 页、`S11` 第 339 页以暗动子孙冲库、生原神为“库之破”，将原本凶象解释为有救。

因此墓、库不能作为多动爻路径的默认硬裁剪原因。

## 四、十二长生之绝

### 1. 绝是力量状态，不自带固定吉凶

`S15` 印刷第 356 页 / PDF 第 371 页、`S11` 第 335 页写：“绝处逢生，凶中有救”，用神逢绝但得动爻生扶，仍可有救。

`S15` 印刷第 183 页 / PDF 第 198 页、`S11` 第 167 页则说忌神休囚又绝、动而入库等“虽不为害，但过时遇旺则凶”。这说明绝主要改变当前力量和时机；用神、原神受绝通常形成阻滞，忌神受绝则可能暂时有利于焦点结果。

### 2. 化绝的应期

`S15` 印刷第 238 页 / PDF 第 253 页、`S11` 第 221 页规定，三合局中如有一爻化绝或临绝，应待生旺之期。这支持：

```text
ABSOLUTE_EFFECT_OPEN
resolution_candidate=GROWTH_RECOVERY
```

不支持直接 `pruned`。

### 3. 十干表与六爻五行表不得混用

`S15` 印刷第 95 页 / PDF 第 110 页的“十天干生旺死绝表”属于十干日主体系，绝位为：

```text
甲申 乙酉
丙亥 丁子
戊亥 己子
庚寅 辛卯
壬巳 癸午
```

六爻章节按爻的五行阶段使用顺行口径，案例明确出现木绝于申、水绝于巳。不得把十干阴阳顺逆表静默套进六爻爻支。不同算法必须使用独立、版本化 profile，并绑定表摘要。

`S10` PDF 第 242 页 / 印刷第 225 页“本命戊土逢戌入墓”是八字与卦象混合判断，属于 `mixed_method_case`，不能用来修改纯六爻长生表。

## 五、飞神、伏神有效性

### 1. 飞伏必须分别评估

`S11` 第 171–172 页列出的方向关系包括：

- 伏神得日月生、旺相、飞神生或动爻生，为有用候选；
- 日月动爻冲克飞神，或飞神空、破、休囚、库、绝，可能有利伏神出现；
- 伏神自身休囚无气、被月冲克、被旺相飞神克害、休囚旬空等，又可能使伏神不得出。

这说明飞神无力可能解除压伏，但伏神自身仍可因另一组条件无力。不得因飞神 `conditional` 就把同位伏神一起裁掉，也不得因伏神存在就自动升级为最终用神。

### 2. 飞生伏的独立案例

`S10` PDF 第 317–319 页 / 印刷第 300–302 页有父母巳火伏于官鬼寅木之下、飞神兼原神且化进，“飞来生伏得长生”的案例。它可支持一条限定的飞生伏候选边，但 `S10` 没有提供飞克伏、伏克飞以及飞伏与旬空、月破、墓、绝的完整交叉矩阵。

### 3. `SOURCE_TEXT_ANOMALY`：伏神库绝语法歧义

`S11` 第 172 页原文有“伏神库绝于日、月飞神者”一句，标点和“日、月、飞神”之间的统属关系不清。不得据此建立月、日、飞神的固定优先顺序。

应记录：

```text
reason_code=SOURCE_TEXT_ANOMALY
anomaly_id=HIDDEN_TOMB_ABSOLUTE_GRAMMAR_172
resolution=scope_and_grammar_unresolved
```

## 六、多动爻路径与规则优先级

### 1. 三本资料没有可执行的统一裁剪算法

`S10` 有“四个爻乱动”或“五个爻都动，主事不顺”一类案例描述，但没有给出：

- 动爻之间固定的先后序列；
- 多条生克路径的统一权重；
- 月破和日破冲突时谁覆盖谁；
- 空、破、墓、绝叠加后的穷举优先级；
- 何时可以把一条仍可能出空、冲库或逢生的路径永久删除。

`S10` PDF 第 240 页 / 印刷第 223 页反而明确说，应期方法“没有一个死板的教条”，要按不同卦象、不同事物采用不同方法。

### 2. 允许的保守裁剪边界

从三本资料能够支持的最小边界是：

```text
可以直接排除：
- 结构上不存在的节点或变爻；
- 当前 profile 明确禁止的边型；
- 与已确认焦点不可达的边或路径；
- 精确重复的同语义路径。

不能直接排除：
- 单一旬空；
- 单一月破或日冲；
- 单一入墓、化墓、入库或化库；
- 单一临绝或化绝；
- 尚可能通过出空、填实、冲空、出月、逢合、冲库、逢生恢复的路径；
- 飞伏显隐条件尚未闭合的路径。
```

路径含任一未闭合节点或边时，事实轴 `validity_status` 应标为 `deferred`，不能因该事实改成传统意义的 `pruned`。循环、长度和焦点无关等工程边界另写入 `enumeration_status=profile_excluded` 与 `enumeration_reason`；这条工程收据不得覆盖或改写事实轴。

### 3. 规则优先级不能使用后写覆盖

建议采用开放义务账本，而不是简单 `if/elif` 或加减分：

```text
输入与来源门禁
  > 结构适用性
  > 月日上下文完整性
  > 空、破、墓、绝、合冲、飞伏原子义务
  > 仅关闭精确匹配义务的例外规则
  > 节点状态
  > 边状态
  > 聚焦路径状态
```

“动不为空”“冲空则实”“冲库”等规则只能关闭自己明确对应的义务，不能把同一节点上的所有条件清零。同优先级规则出现相反效果、题型作用域不清或来源族冲突时，必须生成 `RULE_EFFECT_CONFLICT`，保持未决。

三本资料没有给出“两条边、256 条”的统一传统裁剪算法。因此这两个上限、路径枚举状态和工程优先级必须进入独立的 `engineering_policy` 摘要，不能混入来源规则 profile；来源 profile 只绑定来源身份、页码、文本异常和来源规则合同。

## 冲突矩阵摘要

| 冲突 | 支持 A | 支持 B | 审计裁决 |
|---|---|---|---|
| 旺动逢空是否立即有效 | 邵书引野鹤“旺不为空，动不为空” | 同书动空仍待出旬值日；静空不受生；张志春规则仅限终身卦世爻 | 保留结构资格，当前力量和兑现时间另算；作用域不明时未决。 |
| 临月建能否解除旬空 | 邵书有“值月建，逢空不空” | 同句括注“在旬内者毕竟为空”；`S10` 有临月建仍因空和受克失败的复合案例 | 双轴处理：结构可保留，旬内兑现受阻；不得建立全局覆盖。 |
| 月破是否完全无用 | 月破章节有“虽有如无” | 同章又给出出月、填实、逢合恢复；另有日合后“休囚待时而用” | 当前受抑、未来条件恢复；恢复后仍重算旺衰。 |
| 日冲是暗动还是日破 | 旺相静爻受冲为暗动 | 休囚衰弱静爻受冲为日破 | 旺衰未闭合时保持未决。 |
| 墓、绝是否固定为凶 | 所求用神、原神墓绝常受阻 | 忌神墓绝可能暂时无害；绝得生扶、墓得冲库可救 | 先看节点角色，再看旺衰、救应和时机。 |
| 飞神无力是否使伏神无效 | 飞神旺而克伏可压伏 | 飞神空破休囚库绝反而利于伏神出现 | 飞、伏分别评估；飞神无力可打开显现候选，不能代替伏神自身门禁。 |
| 冲库是否等于结果必成 | 一般应期有“待冲库” | 冲开后仍可能有其他空破墓绝和生克条件 | 只登记解除候选，不输出必然结果。 |

## 不可补造的规则

本次三本资料不足以支持以下规则；注册表中如需暴露，应使用 `not_found` 或 `unsupported_profile`，不得给出自动裁决：

```text
凡墓逢冲必开
冲墓是三书的统一原词
月破与日破冲突时存在固定总优先级
所有旺爻或动爻均可无条件视为不空
所有爻均可无条件套用日建冲空即实
普通日辰生扶即可解除月破
出破或填破存在三书一致的统一通则
飞伏与空破墓绝存在完整交叉矩阵
多动爻存在固定的逐爻裁剪顺序
动爻越多即可据数量直接判吉凶
空破墓绝条件数量可以换算为概率或分数
```

## 实现与审计要求

每条有效性裁决至少应记录：

```text
source_family
source_refs
source_level
source_evidence[]
topic_scope
node_role
policy_id
priority_policy_id
opened_obligations
discharged_obligations
remaining_obligations
reason_code
outcome

source_terms
```

其中工程端点门禁的 `source_refs` 和 `source_evidence` 必须为空，并绑定工程 policy；来源规则命中才绑定书目页码。异质页码不得压成一个合成证据等级：`source_evidence` 中每条引用分别记录 `source_family/source_level/topic_scope/source_terms`，外层 `source_level=per_reference` 只作索引提示。数值 `priority` 另由 `priority_policy_id` 明确绑定工程 policy，不能冒充来源中的传统优先级。

冲库类候选统一使用 `normalized_relation=storage_release_by_clash`，原文术语保留为“冲库”“冲开库”“库之破”，不得自行改造成“冲墓”。两个 `SOURCE_TEXT_ANOMALY` 只进入审计元数据，固定 `activates_rules=false`。

来源引用格式建议保持页码双记：

```text

S11:print:200/pdf:200
S10:print:239/pdf:256
```

所有基于本文的规则仍须保持：

```text
review_only=true
production_allowed=false
prediction_validity=not_evaluated
```

在事前冻结、事后结算的真实样本完成前，不得把本来源审计升级为 `verified`，不得据此输出确定吉凶、确定日期或现实准确率。
