# 小红书评论版受控流程 V1

## 范围

本流程只定义人工运营使用 Comment Mode 的表达边界，不接入平台 API，不自动发布评论，不处理真实客户资料，也不构成商业发布授权。

流程：命盘图片 -> 读取四柱、日主、性别 -> 用户确认读盘 -> 仅选高置信结论 -> 输出 80 或 120 字评论版 -> 评论区仅做初步判断 -> 详细分析进入人工咨询 -> 服务确认后冻结初始输出 -> 收集反馈 -> 经授权匿名进入 Case OS。

## 评论区边界

- 只给 1-2 个高置信重点，不展开 Yuan 八段、称骨或完整五年断事。
- 不承诺结果，不诊断医疗、法律、投资或生死问题。
- 不含联系方式、二维码、支付信息或规避平台治理的变体话术。
- 平台规则可能变化；运营人员使用前必须按当期平台规则复核。

Comment Mode 固定为 `output_mode=comment`、`high_only`、已确认命盘、80/120 字符和末行一次免责声明。它不验证预测准确率，且不改变 Release Hold。
